# IndigoLearn – ACCA landing page (React + Bootstrap)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

- React 18 + hooks (`useState`, `useContext`, `useCallback`, `useMemo`, custom `useForm`)
- UI framework: Bootstrap 5 via `react-bootstrap`
- "Request Call Back" (hero + footer form) opens a success modal via `CallbackModalContext`
